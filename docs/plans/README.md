# Milestone plans (historical)

These are the implementation plans written and approved before each milestone, kept as a record of how AccessFlow was built with an AI coding assistant (see [`CLAUDE.md`](../../CLAUDE.md) and the README's [AI-Assisted Development](../../README.md#ai-assisted-development)). **They are not a to-do list.** Their checkboxes were the working checklist during each milestone and were not ticked afterwards; the agent-instruction headers ("For agentic workers") are part of that working format. Every milestone below is delivered and merged. Where a plan and the code differ, the code and [`DECISIONS.md`](../../DECISIONS.md) are authoritative.
